# Human 2.0 Book Writings

This is the working writing room for the Human 2.0 book. The order is intentional:

1. `part-01-crash-course/` — numbered concepts: where we have come from, where we have been, and how the machinery works.
2. `part-02-field-essays/` — lettered personal essays: how a real person uses these tools to expand their operating range.
3. `part-03-running-the-day/` — individual operating chapters: how Human 2.0 directs, reviews, measures, and learns.

Every chapter begins as a Markdown template and retains its QA checklist while it is drafted, reviewed, and edited through the matching GitHub issue.
